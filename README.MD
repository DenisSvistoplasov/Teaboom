# Teaboom — карточка товара

Адаптивная вёрстка карточки товара «Ананасовый улун» в стилистике интернет-магазина Teaboom.ru.

[Посмотреть демо на GitHub Pages](https://denissvistoplasov.github.io/Teaboom/) · [Оригинальная страница](https://teaboom.ru/product/ananasovij-ulun)

## Возможности

- Изображение, название, категория и описание товара.
- Выбор фасовки: 100, 500, 1000 и 5000 г. При переключении обновляются артикул, актуальная и старая цены, наличие и выделение выбранного варианта.
- Кнопка «В корзину» с обычным состоянием и эффектом при наведении.
- Переключение разделов «Описание», «Свойства» и «Отзывы».
- Управление радиокнопками с клавиатуры: Tab для перехода между группами, стрелки для выбора внутри группы. Фокус обозначен обводкой.
- Адаптивная компоновка для десктопа, планшета и телефона. Целевые ширины задания: 1440, 768 и 375 px; при ширине до 600 px карточка перестраивается в одну колонку.

Реальная корзина и серверная часть не реализованы по условиям задания. В разделах «Свойства» и «Отзывы» оставлены текстовые заглушки; описание товара заполнено.

## Технологии

HTML5, CSS, Vanilla JavaScript. Для компоновки используются CSS Grid и Flexbox. Шрифты Open Sans в формате WOFF2 и изображения WebP хранятся локально. Без фреймворков, Bootstrap, готовых шаблонов и сборщика.

## Локальный запуск

Установка зависимостей и сборка не требуются.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/DenisSvistoplasov/Teaboom.git
   ```

2. Откройте папку `Teaboom` в VS Code с установленным расширением Live Server.
3. Нажмите правой кнопкой на `index.html` и выберите **Open with Live Server**. Обычно страница доступна по адресу [http://127.0.0.1:5500/index.html](http://127.0.0.1:5500/index.html); фактический порт может отличаться.

Также можно использовать любой статический HTTP-сервер, указав корень проекта как папку для раздачи файлов.

## Структура проекта

```text
index.html          — разметка карточки товара
styles/
  reset.css         — сброс базовых стилей
  fonts.css         — подключение шрифтов
  main.css          — оформление и адаптивность
scripts/
  product.js        — данные фасовок и переключение разделов
assets/             — изображение товара и фоновый узор
fonts/              — локальные шрифты Open Sans
```
